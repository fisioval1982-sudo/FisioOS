# Reference Infographics Library Standard

## Purpose

Use external infographic references as structured evidence for building the FisioForYou visual system without copying them directly.

## Core principle

A reference may influence the system only through explicit analysis and approved decisions.

## Pipeline

```text
Source reference
↓
Reference registration
↓
Structured analysis
↓
Candidate visual decisions
↓
Human review
↓
Approved decisions
↓
Design system / renderer
```

## May be extracted

- macro layout;
- hierarchy;
- spatial relationships;
- density;
- component categories;
- typography roles;
- spacing behavior;
- color-function relationships;
- illustration placement;
- annotation patterns.

## Must not be copied automatically

- exact branding;
- logos;
- proprietary icon sets;
- copyrighted text;
- unique illustrations;
- distinctive trade dress;
- arbitrary CSS/HTML.

No extracted pattern becomes FisioForYou policy until explicitly approved.
