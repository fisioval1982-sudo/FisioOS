# FisioOS Infographic Renderer

This directory is reserved for the deterministic renderer implementation.

## Current phase

Foundation only.

No canonical HTML/CSS renderer is implemented yet.

## Planned modules

- input validation;
- specification normalization;
- component resolver;
- token resolver;
- asset resolver;
- render-plan generator;
- output adapters.

## Rule

Do not add generative behavior to the renderer.
