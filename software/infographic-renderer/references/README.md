# Reference Infographics Library

This library stores external infographic references used to extract reusable visual patterns for the FisioForYou infographic system.

References are evidence inputs, not canonical FisioForYou designs.

## Structure

```text
references/
├── source/
├── analysis/
└── decisions/
```

## Workflow

Reference → Analysis → Proposed decision → Human approval → Approved system rule

Never copy a reference directly into production.
