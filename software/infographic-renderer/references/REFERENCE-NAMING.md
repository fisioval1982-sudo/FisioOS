# Reference Naming Convention

Use immutable IDs:

```text
REF-INFOGRAPHIC-000001
REF-INFOGRAPHIC-000002
```

Source filename: `REF-INFOGRAPHIC-000001__source.ext`
Analysis filename: `REF-INFOGRAPHIC-000001__analysis.json`
Decision filename: `REF-INFOGRAPHIC-000001__decisions.json`

Preferred source formats: PNG, JPG/JPEG, PDF. Preserve the original source whenever possible.
